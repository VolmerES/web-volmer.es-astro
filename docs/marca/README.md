# Kit de marca de Volmer Studio

El kit vive en un lienzo de Claude (cuenta personal):
**https://claude.ai/artifact/Chdm5qLuTWvWRjSkGk1uVR**. Es privado; para que lo
vea otra persona hay que compartirlo desde su menú Share. Las imágenes se
exportan desde ahí (PNG para redes, PDF para la tarjeta).

Esta carpeta es la copia del código fuente, por si el lienzo se pierde:
`lienzo/` tiene el índice (`canvas.json`) y una pieza por fichero (`*.dc.html`),
y `recursos/` los QR. Las fotos que usan las piezas (`/_blob/…`) son
`public/profile.png`, `public/drone.png` y `public/laptop.png` de este repo,
subidas al lienzo.

## Sistema

| | |
|---|---|
| Fondo | Tinta `#0A0A0A`, superficie `#121212` |
| Texto | `#F4F4F5`, secundario `#A1A1AA` |
| Principal | Cian `#05D9E8`: enlaces, botones, datos |
| Firma | Rosa `#FF2A6D`: el punto del logo y, como mucho, un acento por pieza |
| Profundidad | Morado `#320A5C`, solo en brillos |
| Sobre claro | Cian oscuro `#0E7490` y rosa oscuro `#E11D5C` (contraste) |
| Tipografía | Outfit 800 titulares · Geist texto · Geist Mono etiquetas |
| Logo | «VOLMER.» con el punto rosa + «STUDIO» en mono; monograma «V.» |

Degradado cian → rosa solo en líneas finas, nunca de fondo.

## Piezas

Página **Español**: hoja de marca, favicon (512 y tamaños), imagen al compartir
(1200 × 630), Google Business (logo 720, portada 1080 × 608, publicación
1200 × 900), LinkedIn (logo 400, portada 1128 × 191, publicación 1200 × 627),
firma de correo (600 × 200) y tarjeta de visita (cara y dorso).

Página **English**: las mismas con texto, traducidas. El QR del dorso inglés
apunta a `volmer.es/en/`.

## Tarjeta de visita

Formato estándar en España: **85 × 55 mm**. El archivo mide 91 × 61 mm porque
lleva 3 mm de sangrado por lado, que la imprenta recorta; las guías rosas del
lienzo marcan la línea de corte. El texto queda a más de 6 mm del borde final.
La cara es negra: pedirla en papel mate y con negro enriquecido.

## Firma de correo

Lo que va dentro de la imagen no se puede pulsar: poner debajo el teléfono, el
correo y la web también como texto.
